<Warning>
This is the **v2** endpoint. New integrations should use [Fetch Alerts (v3)](/api-reference/alerts/fetch-alerts-v3), which adds network/status/date filtering, matched-vs-unmatched fields, and BIN details. Switch to the **v3** version in the sidebar version dropdown.
</Warning>

<Info>
The `subprovider` field indicates the alert network. See [Alert Types](/reference/alert-types) for all possible values and descriptions.
</Info>

<Info>
Each alert may include optional **`attributes`**: a dictionary of string keys and string values (for example `order_number`, `processor_id`). The same field appears on [webhook](/api-reference/webhooks/setup#body) payloads when present.
</Info>
